📘 Project Overview
This project implements a 3-bit Conditional Adder/Subtractor (CASU) using basic digital logic gates.
The circuit performs different arithmetic operations based on the comparison between two unsigned 3-bit inputs A and B.

To reduce IC count and circuit complexity, an optimized logic strategy is used.
When A equals B, addition is implemented using a left-shift operation instead of a full adder.
When A is not equal to B, the circuit computes the absolute difference |A − B|.

Only basic logic gates are used: AND, OR, NOT, XOR, and XNOR. No arithmetic ICs are used.

🎯 Problem Statement
Given two 3-bit unsigned binary numbers A and B:

If A = B, the output is A + B
If A ≠ B, the output is |A − B|

🔢 Inputs and Output

➡ Inputs
A = A2 A1 A0
B = B2 B1 B0

⬅ Output
Y = Y2 Y1 Y0

🧠 Design Summary

✔ Equality Check
XNOR-based comparator checks whether A equals B.

➕ Addition Logic
When A equals B, the output is generated by left-shifting A (A + B = 2A).

🔍 Magnitude Comparison
A B < A comparator determines the subtraction order.

➖ Subtraction Logic
If B < A, compute A − B
Otherwise, compute B − A

🔀 Final Selection
Gate-based multiplexing selects between the shifted output and the subtraction result.
